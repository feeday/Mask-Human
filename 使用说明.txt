人像黑白蒙版工具

一键打包：双击 build_exe.bat，生成 dist\Mask-Human.exe。
EXE 内含 Python 运行环境，可以复制到其他 Windows x64 电脑使用。
模型不内嵌，首次运行下载并缓存；离线使用方法见 README.md。
GitHub 在线打包：Actions → Build Windows EXE → Run workflow。

默认使用 BiRefNet Portrait 人像模型（1024 分辨率推理）。
旧版 U2Net 在遮挡和复杂背景下可能误把背景识别成人物，现已替换默认模型。
新模型首次运行需要另外下载，CPU 处理会比旧版慢。
不自动处理已有的 .mask.png 蒙版文件。

1. 双击 run_portrait_mask.bat，在弹出的窗口中选择图片文件夹。
   也可以把一个文件夹拖到 BAT 文件上运行。
2. 自动处理该文件夹及子文件夹的图片。
3. 输出位于所选文件夹内的“人像蒙版_时间”文件夹，保留子目录结构。
   人物（包括头发、衣服、身体）为纯白色 255，其他区域为纯黑色 0。
   同一张照片中的人物合并在一张蒙版中，不逐个拆分。
   原图不修改；图片方向按 EXIF 校正，输出与校正后的原图尺寸一致。

支持 JPG、JPEG、PNG、WEBP、BMP、TIF、TIFF。动图/多页图片仅处理第一帧。
首次运行需要联网，自动安装独立 Python 3.12 环境、依赖并下载模型。
后续使用已缓存的模型在本机 CPU 上处理，无需上传图片。
本机需要已有 Python（当前电脑已安装），无需手工安装依赖。
请保留 BAT 与两个 PY 文件在同一目录，运行过程中不要关闭窗口。
模型自动识别可能有漏分或误分，遮挡、复杂背景或很小的人物需要检查结果。

可选命令行：
run_portrait_mask.bat "D:\照片" --threshold 127
阈值范围 1～254：降低阈值会扩大白色区域，提高阈值会缩小白色区域。

模型与依赖项目：https://github.com/danielgatis/rembg
